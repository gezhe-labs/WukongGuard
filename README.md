# 后悔药 · 游戏防遗漏提醒

后悔药在《黑神话：悟空》的候选遗漏地点显示游戏内提醒。默认只提醒可能无法补救的内容；可在设置中额外开启隐藏地区提示。提醒采用渐进式揭示，普通弹窗不抢游戏焦点，10 秒后自动收起。

**当前为 0.5.0-rc1 验证版。** 已配置 7 条不可补救内容提醒与 6 条可选隐藏地区提示。规则主要依据章节、地图和坐标，尚不能可靠判断每项内容在当前周目是否已完成；只有第一章幽魂风险点做过一次正向实机验收。请勿将其视为已完成六章实测的 1.0。

## 下载与使用

下载 `后悔药-0.5.0-rc1.exe`，在**游戏未运行时**双击。首次打开会自动寻找 Steam 游戏目录、校验并准备依赖；可能需要联网下载 B1CSharpLoader 和允许一次 Windows 管理员授权。准备完成显示“已就绪，等待游戏启动”。然后由玩家自行从 Steam 启动《黑神话：悟空》。以后每次游戏前打开同一个 EXE 即可，无需重复安装。找不到游戏时，在首页选择 `BlackMythWukong` 目录。

游戏退出后，本次提醒自动停用。点击托盘“退出后悔药”也会立即撤销会话许可；如游戏仍在运行，后台清理进程会等游戏退出后删除本次启用的 Mod DLL。准备过的 B1CSharpLoader 依赖保留在游戏目录；因此单独从 Steam 启动时加载器本身仍可能加载，但后悔药 Mod 不会执行提醒。

已有的隐藏地区、快捷键和手柄设置继续从 `%LOCALAPPDATA%\WukongGuard\settings.json` 读取。设置、提醒记录和诊断集中在 EXE 主窗口；游戏内托盘只保留快捷入口与退出。首次配置会备份既有 `b1cs.ini`，将 `Console=0`、`EnableJit=0`，以隐藏加载器控制台并沿用本机已验证的修改器兼容设置。此改动也作用于共用同一加载器的其他 Mod。为避免每次启动都请求管理员权限，首次配置只给当前用户在后悔药 Mod 子目录的修改权限。

## 使用提醒

普通提醒显示时按 `Ctrl+Shift+G`，或用 Xbox 手柄长按 `Menu` 约 1 秒，可打开可操作的详情窗口。键盘快捷键可在设置中改为 `Ctrl+Alt+Shift+G`。手柄 Menu 可能同时打开游戏菜单，手柄入口尚需实机验收。诊断页的“显示测试提醒”仅测试 UI，不表示附近真的有遗漏。

当前的正式规则、候选触发地点和已知限制见 [插件说明](WukongGuard/README.md)。运行时探针见 [WukongStateProbe](WukongStateProbe/README.md)。构建方式见 [开发与发布检查](docs/release-checklist.md)。

本仓库只跟踪可公开的源码、规则和文档。游戏程序集、存档、实机日志及构建产物不进入 Git；EXE 作为独立发布附件交付。
