# 后悔药 · 游戏防遗漏提醒

后悔药在《黑神话：悟空》的候选遗漏地点显示游戏内提醒。默认只提醒可能无法补救的内容；可在设置中额外开启隐藏地区提示。提醒采用渐进式揭示，普通弹窗不抢游戏焦点，10 秒后自动收起。

**当前为 0.5.0-rc5 验证版。** 已配置 7 条不可补救内容提醒与 6 条可选隐藏地区提示。规则主要依据章节、地图和坐标，尚不能可靠判断每项内容在当前周目是否已完成；只有第一章幽魂风险点做过一次正向实机验收。请勿将其视为已完成六章实测的 1.0。

## 下载与使用

下载 [后悔药 0.5.0-rc5 EXE](https://github.com/gezhe-labs/WukongGuard/releases/download/v0.5.0-rc5/%E5%90%8E%E6%82%94%E8%8D%AF-0.5.0-rc5.exe)，在**游戏未运行时**双击，点击首页的“启动保护”。首次启动保护会校验并准备依赖；可能需要联网下载 B1CSharpLoader 和允许一次 Windows 管理员授权。准备完成显示“已就绪，等待游戏启动”，按钮变为“取消待命”。随后由玩家自行从 Steam 启动《黑神话：悟空》。以后每次游戏前打开 EXE、点击“启动保护”即可，无需重复安装。找不到游戏时，在游戏卡片选择 `BlackMythWukong` 目录。打开或再次双击 EXE 本身不会启用保护。

游戏退出后，本次提醒自动停用；下一次游玩点击“重新启动”。“取消待命”或“停止保护”会立即撤销本次会话许可。点击关闭窗口会提示收起到托盘，可选择取消或勾选“不再提醒”（重启后仍有效）。收起到托盘时保护状态不变；点击托盘“退出后悔药”才结束应用。若退出时游戏仍在运行，隐藏清理进程会等游戏退出后删除本次启用的 Mod DLL，并避免干扰新会话。准备过的 B1CSharpLoader 依赖保留在游戏目录；因此单独从 Steam 启动时加载器本身仍可能加载，但后悔药 Mod 不会执行提醒。

已有的隐藏地区、快捷键和手柄设置继续从 `%LOCALAPPDATA%\WukongGuard\settings.json` 读取。提醒设置、提醒记录和诊断集中在《黑神话：悟空》卡片的“游戏配置”窗口，本版没有全局设置。游戏启动后由 EXE 统一管理托盘。首次配置会备份既有 `b1cs.ini`，将 `Console=0`、`EnableJit=0`，以隐藏加载器控制台并沿用本机已验证的修改器兼容设置。此改动也作用于共用同一加载器的其他 Mod。为避免每次启动都请求管理员权限，首次配置只给当前用户在后悔药 Mod 子目录的修改权限。

游戏卡片优先显示玩家本机 Steam 缓存中的官方横幅，图片不随 EXE 和源码再分发。缓存不存在时显示备用背景，不影响保护功能。长目录会简洁展示，悬停可看完整路径，点击路径可复制。

## 使用提醒

普通提醒显示 10 秒，不获取焦点，鼠标点击穿透到游戏。游戏在前台且提醒显示时按 `Ctrl+Shift+G`，或用 Xbox 手柄重新按住 `Menu` 约 1 秒，可打开可操作的详情窗口；弹窗出现前已经按住的 Menu 不会打开详情。键盘快捷键可在游戏配置中改为 `Ctrl+Alt+Shift+G`。详情在前台时可用手柄 A 逐步查看、B 关闭并返回游戏；切换到其他应用时不响应详情中的手柄输入。手柄 Menu 可能同时打开游戏菜单，手柄入口尚需实机验收。游戏配置的诊断页可以发送测试提醒、打开日志目录或导出诊断；测试提醒不表示附近真的有遗漏。

rc5 修正普通提醒置顶时可能获取焦点的问题。Windows 桌面自动验证检查窗口样式、鼠标穿透和整个倒计时期间不激活提醒；这不能代替 Xbox 手柄在游戏内的实际验收。输入事件诊断写入 `%LOCALAPPDATA%\WukongGuard\overlay.log`，导出诊断时一并收集。

当前的正式规则、候选触发地点和已知限制见 [插件说明](WukongGuard/README.md)。运行时探针见 [WukongStateProbe](WukongStateProbe/README.md)。构建方式见 [开发与发布检查](docs/release-checklist.md)。

本仓库只跟踪可公开的源码、规则和文档。游戏程序集、存档、实机日志及构建产物不进入 Git；EXE 作为独立发布附件交付。
