# WukongGuard 0.4.0-rc11 本机测试包

本包按用户提供的两份转写稿设置 **7 条默认失效提醒**（对应 7 类内容）和 **6 条可选隐藏地区提示**。隐藏地区均可回访，默认不提醒。

## 安装

前提：Windows PC 版《黑神话：悟空》已安装 B1CSharpLoader v0.0.8。覆盖层运行时已随包提供。

退出游戏，解压 ZIP，在解压目录运行：

```powershell
.\release\install.ps1
```

若未找到游戏，传入 `-GameRoot '<游戏安装目录>'`。安装脚本备份旧版本并写入新规则，安装完成后默认停用。要体验插件，先运行 `.\release\start-session.ps1` 并保持窗口打开，再通过 Steam 启动游戏；游戏退出后脚本自动停用。推荐直接使用单文件 EXE 操作相同流程。

## 设置与验证

系统托盘 WukongGuard 图标 → **设置 → 隐藏地区提示（默认关闭）**，勾选后约 3 秒生效。配置保存在 `%LOCALAPPDATA%\WukongGuard\settings.json`，升级时保留。

默认提示只在候选风险地点附近自动出现。初始提醒不抢游戏焦点，10 秒后关闭。提醒显示时按 `Ctrl+Shift+G` 或 Xbox 手柄长按 `Menu` 约 1 秒进入详情，详情不会自动关闭；鼠标点击“更多提示”、键盘 Enter、手柄 A 可逐级揭示，Esc 或手柄 B 关闭。托盘“最近提醒”可重看，“测试提示交互”可先验证输入，不表示附近有遗漏。托盘“设置”可切换键盘快捷键、关闭手柄长按入口。Menu 可能先打开游戏菜单，详情关闭后需要自行退出游戏菜单；手柄入口尚待实机验证。日志位于 `%LOCALAPPDATA%\WukongGuard\guard.log`，命中后查看 `matched` 与 `delivered` 行。

开启隐藏地区提示后，抵达相关土地庙附近不会立即弹出；进入候选范围并继续走动约 3 秒后才提示，往外走的一小段路也会继续计时，原地停留不会触发。这项时机仍需游戏内校准。不可补救提醒维持接近风险点时立即触发。

**本版是实机校准包，尚未完成新周目的全部正向验收。** 第一章旧观音禅院前的提醒已有一次真实游戏正向验证。所有正式规则仅能确认玩家接近风险地点，尚不能可靠读取对应内容在当前周目的完成状态；已完成该内容的玩家仍可能看到条件提醒。其余地点的战前提前量需实机确认。详细清单和触发地点见随包 `data\ch1-ch6-missables.json`、`data\hidden-areas.json` 和项目 README。

规则不限制一周目。停留在触发范围内只提醒一次；离开范围及缓冲距离后再次进入，会再次提醒。跨地图返回和进入下一周目也可再次触发。重启游戏会清空会话触发记录。

## 与修改器共用

B1CSharpLoader 的 `CSharpLoader\b1cs.ini` 若设置 `EnableJit=1`，加载器作者明确指出风灵月影等部分修改器可能失效。WukongGuard 目前不使用 Harmony Hook。本机已验证的共用配置是 `EnableJit=0`：备份原配置、修改后完全退出并重启游戏，风灵月影恢复且 WukongGuard 托盘显示“实时读取正常”。真实规则弹窗仍需在对应节点验收。发行配置关闭 Ctrl+F8 演示快捷键，按键无响应不代表插件失效。

## 卸载

退出游戏后运行 `.\release\uninstall.ps1`。默认保留配置和旧版本备份；加 `-PurgeSettings` 删除配置。故障日志可用 `.\release\export-diagnostics.ps1` 导出。
