# 后悔药 0.5.0-rc1 · 《黑神话：悟空》模块

本版按用户提供的《错过就无法完成的任务》和《防剧透的全隐藏地区指南》重新划分提醒：

- 默认：7 个风险地点提醒，对应原文 7 类不可补救内容。
- 可选：6 个可回访隐藏地区提示，默认关闭。打开后悔药 EXE 主窗口 → **设置 → 额外显示隐藏地区提示** 即可启用；约 3 秒内生效，设置保存在 `%LOCALAPPDATA%\WukongGuard\settings.json`。
- 弹窗使用四级渐进提示。初始提醒不抢游戏焦点，只显示明确的失效后果，10 秒后自动收起。提醒出现期间按 `Ctrl+Shift+G`，或用 Xbox 手柄长按 `Menu` 约 1 秒，才打开可操作的详情窗口；在详情里点击“更多提示”、按 Enter 或手柄 A 逐级揭示，按 Esc、手柄 B 或点击“关闭”返回游戏。详情没有自动关闭倒计时。

EXE 主窗口 **设置 → 查看更多的键盘快捷键** 可在 `Ctrl+Shift+G` 与 `Ctrl+Alt+Shift+G` 间选择。如果首选键被其他程序注册，本次提醒自动尝试另一个，并在弹窗上显示实际按键；两个都不可用时，可从托盘“最近提醒”打开详情。主窗口还能关闭“手柄长按 Menu 查看详情”。手柄 Menu 可能先打开游戏菜单，详情关闭后需要在游戏中自行退出菜单。手柄输入尚待实机验证；Steam Input 或其他映射工具可能影响识别。

游戏线程每秒只读采样章节、地图、坐标和可用任务状态。规则采用确定性匹配。**第一章旧观音禅院前的真实提醒已完成一次正向实机验收；章节 2、3 的实时状态及第二章坐标系曾做校准。其余触发点的前置距离仍待实测。全部正式规则目前都不能可靠判断对应内容在当前周目是否已经完成，因此使用条件性文案；抵达风险地点可能提示已完成的玩家。** 本版用于新周目验证，不应称作六章完整防遗漏的 1.0。

**重复提醒与多周目：**同一地点停留时只提醒一次；离开触发范围及一小段缓冲距离后，再进入会重新提醒。跨地图返回及进入下一周目也可再次触发。缓冲距离为游戏坐标 `max(300, 触发半径的 10%)`，用于避免在范围边缘反复弹窗。沙二郎提醒不依赖可能从上一周目保留的任务记录。游戏重启会清空当前会话的触发记录；每个周目的剧情坐标和弹窗提前量仍需实机验收。

原文明确说这六处隐藏地区本身可回访，因此可选提示不声称它们会永久错过。梅山提示设在第五章后期，用于提示多章节前置条件，并非游戏内梅山入口。启用后同一地点若同时命中两类规则，覆盖层依次展示，不会互相覆盖。

六处可选提示需要先进入土地庙附近的候选范围，之后累计约 3 秒实际移动才会出现。玩家从土地庙直接往外走时，计时会在附近道路继续，最多延伸到候选中心约 50 米；原地停留不会触发，走出该范围后重新进入才会重新计时。每秒采样一次，因此弹出时刻可能有约 1 秒误差。默认不可补救提醒不延迟，确保仍在风险行为之前出现。新的外行路径仍需实机验收。

## 安装与验证

开发工作区内，退出游戏与覆盖层后执行：

```powershell
.\WukongGuard\tools\build.ps1
.\WukongGuard\tools\install.ps1 -UpdateRules
.\WukongGuard\tools\start-overlay.ps1
```

面向玩家使用单文件 `后悔药-0.5.0-rc1.exe`：游戏未运行时打开，首次自动准备，显示待命后自行从 Steam 进入游戏。ZIP 与 `release` 脚本保留为开发者诊断用途。需要 B1CSharpLoader v0.0.8；EXE 自带 .NET 8 Desktop Runtime。无需手动报告土地庙或按快照键。托盘“状态”应显示失效提醒 7 条；默认隐藏地区关闭。日志在 `%LOCALAPPDATA%\WukongGuard\guard.log`，命中后应依次出现 `matched <rule-id>` 和 `delivered <rule-id>`。初始提醒 10 秒后自动收起；托盘“最近提醒”可重看；EXE“诊断 → 显示测试提醒”可安全体验按键，不表示附近有遗漏。

游戏未到对应地点时保持静默。第一章幽魂风险提示已做一次实机正向验收；其余规则以及新的隐藏地区移动门槛仍待逐点验证。看到编译通过或 `active rules=13` 只表示规则已加载。

## 与修改器共用

B1CSharpLoader 的 `CSharpLoader\b1cs.ini` 若设置 `EnableJit=1`，加载器作者明确指出部分修改器（包括风灵月影）可能失效。WukongGuard 目前不使用 Harmony Hook；本机在备份配置并设为 `EnableJit=0`、完全重启游戏后，玩家确认风灵月影恢复，WukongGuard 托盘仍显示“实时读取正常”。第一章幽魂风险弹窗已获一次实机确认；其余规则仍待验证。发行配置 `experience.json` 的 `DevelopmentMode=false`，因此 Ctrl+F8 演示快捷键不会响应，不能据此判定插件失效。

内容关系见 `data/ch1-ch6-missables.json` 和 `data/hidden-areas.json`。风险坐标初稿参考 [wukong-minimap 地图数据](https://github.com/jaskang/wukong-minimap/blob/main/data.js)，使用本机黄袍员外位置交叉核对过坐标系；每个触发点仍需实机验证。用户提供的转写稿是内容判断基准，其中带有口播广告，未进入插件内容。
