# 后悔药 0.5.0-rc5 界面与使用流程

## 首页

品牌名：后悔药。

一句话说明：在错过之前提醒你，避免遗漏无法补救的支线与隐藏内容。

首页展示支持的游戏卡片。当前可选《黑神话：悟空》，旁边展示“更多游戏更新中”的占位卡片。游戏卡片包含游戏图片、当前状态、简短说明、游戏目录和该游戏的配置入口。本版本没有全局设置入口。

背景图片优先读取玩家本机 Steam 缓存中的游戏图片，不随 EXE 分发原图；缓存缺失时使用渐变背景。自动识别的长目录采用简短展示，悬停显示完整路径，点击复制；“选择目录”支持手动修正并校验目录。

## 启动流程

1. 打开 EXE：显示首页，尚未启用本次保护。
2. 点击“启动保护”：校验游戏目录、准备依赖、启用会话；首次写入受保护的游戏目录可能出现 Windows 管理员授权。
3. 显示“取消待命”：用户自行从 Steam 启动游戏。
4. 游戏启动：显示“连接中…”，等待运行时数据；获得新鲜数据后显示“停止保护”。
5. 游戏退出：停止本次会话，显示“重新启动”。

点击主窗口关闭按钮会先显示收起提示，可选择“收起到托盘”或“取消”。勾选“不再提醒”并确认后保存到本机；再次打开 EXE 后也会直接收起，不再弹出提示。取消不会保存勾选，也不会停止保护。托盘“退出后悔药”会直接停止保护并退出，不显示收起提示。

主按钮和按钮下方状态说明与“更多游戏更新中”卡片的右边缘对齐，说明文字右对齐并自动换行。首页不展示“运行状态说明”入口或常驻托盘说明，诊断保留在游戏配置内。

取消待命后、或退出后，在下一次启动游戏前需再次打开 EXE 并点击启动。首次准备的依赖保留；退出时停用本产品的 Mod，不反复删除依赖。

如果 EXE 打开时游戏已运行但保护尚未启动，显示“等待游戏退出”，提示退出游戏再开始。连接异常时提供“查看诊断”，并允许停止保护。

| 状态 | 主按钮 | 说明目的 |
| --- | --- | --- |
| 未启动 | 启动保护 | 点击后再自行启动游戏 |
| 准备中 | 正在准备… | 说明目录及依赖准备，按钮禁用 |
| 待命 | 取消待命 | 提示现在从 Steam 启动游戏 |
| 等待运行时数据 | 连接中… | 说明等待进入游戏，按钮禁用 |
| 实时读取正常 | 停止保护 | 说明正常运行及关闭窗口后继续 |
| 数据连接异常 | 查看诊断 | 提供诊断入口和停止保护操作 |
| 准备失败 | 重试启动 | 显示错误与重试方向 |
| 本次游戏结束 | 重新启动 | 提示下次启动前再次启用保护 |
| 游戏已提前运行 | 等待游戏退出 | 退出游戏后再点击启动 |

## 游戏配置

卡片内“游戏配置”进入本游戏配置窗口，分为：

- 提醒设置：不可补救提醒常开；隐藏地区提示可选；键盘及手柄快捷键配置；10 秒倒计时和主动打开详情的说明。
- 提醒记录：查看本游戏的提醒、逐级展开信息、刷新和清空记录。
- 诊断：连接状态、测试提醒、打开日志目录和导出诊断包。

## 提醒与输入

普通提醒为不激活、鼠标穿透的置顶窗口，显示 10 秒后自动关闭。游戏在前台时，Ctrl+Shift+G 或松开后长按 Menu 1 秒才进入详情；不会因弹窗显示、普通点击或倒计时结束而进入详情。详情中的 A/B 只在详情位于前台时有效；从游戏主动打开并关闭详情时返回游戏，从其他应用关闭时保留其他应用的焦点。

保留现有偏好及记录。由主程序管理的游戏覆盖层不再显示第二个托盘图标。退出仍保留在主程序托盘底部。

## 视觉与验证

采用深色背景、金色主操作、游戏背景图及统一圆角卡片和按钮。按钮填充、描边、悬停、按下、焦点和禁用状态统一绘制。首页支持小窗口滚动；配置及详情窗口支持缩放和长文本滚动。主程序启用 PerMonitorV2 DPI。

按钮每次绘制先还原其下方的图片或页面背景，随后绘制填充与描边；实际控件区域也按圆角裁剪，在尺寸和 DPI 变化后更新。避免重复使用绘制缓冲区时，未覆盖的四角保留旧颜色或矩形边缘。

离线验证使用模拟游戏目录和隔离的会话、设置、历史数据，避免更改真实存档或游戏安装。125% / 150% 截图为布局尺寸模拟，仍需在实际显示器 DPI 切换及真实游戏连接中验收。

本次修改不改变提醒规则、条件、重复触发策略或任务状态映射。
